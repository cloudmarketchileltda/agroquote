# AgroQuote Pro — Maqueta Funcional

Este proyecto es una maqueta funcional completa de una plataforma SaaS B2B para la industria agrícola e industrial. Está diseñado para simular el flujo comercial de **Francisco Valenzuela**, permitiendo realizar cotizaciones técnicas, gestionar catálogos de maquinaria y realizar seguimiento de proyectos.

## 🚀 Tecnologías
- **Core**: Next.js 14 (App Router)
- **Estilos**: Tailwind CSS 4.0
- **Iconos**: Lucide React
- **Tipografía**: Inter & JetBrains Mono
- **Animaciones**: Tailwind Animate

## 📦 Módulos Implementados
- **Dashboard Ejecutivo**: Vista general con KPIs de ventas, cotizaciones recientes y seguimiento de proyectos.
- **Catálogo CPQ**: Gestión de productos con categorías técnicas (Maquinaria, Invernaderos, Riego, IoT).
- **Detalle de Producto**: Ficha técnica ultra-premium con especificaciones industriales y gestión de stock.
- **Configurador de Cotizaciones**: Constructor dinámico con cálculo automático de impuestos e inversiones.
- **Directorio de Clientes**: CRM básico para gestión de socios comerciales.
- **Seguimiento de Proyectos**: Visualización de progreso de instalaciones y servicios técnicos.
- **Centro de Reportes**: Analítica visual de rendimiento y distribución de ventas.
- **Configuración**: Panel de administración de cuenta y branding.
- **Login**: Acceso premium con estética industrial tech.

## 🛠️ Desarrollo Local
1. Instalar dependencias: `npm install`
2. Ejecutar servidor de desarrollo: `npm run dev`
3. Abrir en el navegador: `http://localhost:8080`

## 📝 Notas de la Maqueta
- Todos los datos son **estáticos (mock data)**.
- No requiere base de datos real para la demostración.
- El diseño es **Totalmente Responsive**.
- Estética inspirada en Apple Industrial, John Deere y Salesforce.
